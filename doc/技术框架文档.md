# 项目技术框架文档

## 📋 项目概述

**项目名称**: comic-picture-book（漫画绘本创作工坊）  
**项目描述**: AI驱动的智能漫画绘本创作工具，支持故事脚本生成、自动生成卡通风格漫画绘本、用户认证、作品管理等完整功能  
**开发模式**: SPA（单页应用）模式，客户端渲染 + Next.js App Router API 路由  
**版本**: 1.0.0
**定位**: 本地/内网演示项目，尚未接入生产级鉴权与持久化

---

## 🛠️ 核心技术栈

### 前端框架
- **Next.js**: `^16.0.7` - React全栈框架（App Router）
- **React**: `^18.3.1` - UI库
- **React DOM**: `^18.3.1` - DOM渲染

### 开发语言
- **TypeScript**: `^5.0.0` - 类型安全的JavaScript超集
- **配置**: 严格模式，ES2020目标，支持JSX

### 样式方案
- **Tailwind CSS**: `^3.3.0` - 实用优先的CSS框架
- **PostCSS**: `^8.4.0` - CSS后处理器
- **Autoprefixer**: `^10.4.0` - 自动添加浏览器前缀

### HTTP客户端
- **Axios**: `^1.6.0` - Promise基础的HTTP客户端

### 工具库
- **JSZip**: `^3.10.1` - ZIP文件生成和打包工具

### AI服务集成
- **DashScope（阿里云百炼）文本生成**: 用于故事大纲/剧本/分镜生成（统一走 `text-generation/generation`）
- **七牛云API** (qnaigc.com): 用于图像生成（卡通风格漫画）
- **通义万相（DashScope 文生图，可选）**: 用于图像生成（异步任务模式）

## 🔧 技术特性

### 1. Next.js App Router架构
- 使用最新的App Router（Next.js 13+）
- 支持服务端API路由和客户端组件
- 文件系统路由

### 2. SPA模式
- 所有页面组件使用 `'use client'` 指令
- 客户端渲染，提升交互体验
- API路由仍在服务端运行（用于安全处理API密钥）
- 状态持久化（使用sessionStorage）

### 3. TypeScript严格模式
- 完整的类型定义
- 类型安全保证
- 路径别名：`@/*` 映射到项目根目录

### 4. 用户认证系统
- 基于 localStorage 的演示级用户认证（无后端鉴权/密码加密，不可用于生产）
- 支持注册、登录、登出
- 用户信息管理（VIP状态、昵称等）

### 5. 安全与访问控制系统
- **API 保护**: 使用 `withApiProtection` 高阶函数封装 API 路由，支持基于 API Key 的访问校验。
- **频率限制**: 内置 `rateLimiter`，防止 API 被恶意刷取。
- **CORS 管理**: 统一的 `corsHandler` 处理跨域请求，支持局域网开发环境安全访问。
- **错误掩码**: 生产环境下自动屏蔽服务端敏感错误堆栈。

### 6. 图片存储与自动化管理
- **自动保存**: 图像生成后自动下载并存储到 `public/comic-assets/`。
- **元数据绑定**: 每个图片关联一个 `.meta.json`，记录 scriptId、segmentId 和过期时间。
- **自动清理**: 应用启动时自动扫描并删除超过 7 天的过期图片。

### 7. 绘本渲染与导出
- **Canvas 渲染**: 在浏览器端使用 Canvas 动态合成背景图、对话气泡和旁白。
- **离屏渲染导出**: 导出 ZIP 时，使用 `comicPageRenderer.ts` 在后台渲染包含气泡的完整图片，确保下载内容与预览一致。

### 8. 角色一致性技术 (Character Consistency)
- **布局提示词 (Layout Hint)**: 根据分镜中的 `x_ratio` 自动计算角色方位，并在 Prompt 中加入构图指令，防止角色站位错乱。
- **参考图转换**: 自动将本地角色立绘转换为 Base64 传递给模型，支持图生图（i2i）和参考图生成模式。
- **坐标校准**: 自动纠正 LLM 生成的对白气泡坐标，确保气泡始终指向说话人头部区域。

## 🔌 API集成

### DashScope（阿里云百炼）文本生成
**用途**: 故事大纲生成（JSON）、故事剧本生成（半结构化文本）、分镜结构化（JSON）

**主要功能**:
- `generateOutline()` - 生成故事大纲（JSON）
- `generateStoryScript()` - 生成故事剧本（半结构化文本）
- `generateStoryboard()` - 生成结构化分镜（JSON）
- `continueStoryConversation()` - 继续对话完善剧本

**配置**:
- API端点: `https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation`
- 环境变量: `DASHSCOPE_API_KEY`
- 客户端封装: `lib/providers/dashscope/text.ts`
- 业务编排: `lib/storyGenerator.ts`

**三阶段模型选择（带失败回退）**:
- **大纲（JSON）**: `qwen-flash`（`enable_thinking=false`）→ `qwen3-30b-a3b-instruct-2507` → `deepseek-r1-distill-qwen-14b`
- **剧本（半结构化文本）**: `qwen2.5-72b-instruct` → `deepseek-v3.2` → `deepseek-r1-distill-qwen-32b` → `deepseek-r1-distill-qwen-14b`
- **分镜（JSON）**: `qwen3-next-80b-a3b-instruct` → `qwen2.5-72b-instruct` → `qwen3-max`

### 七牛云API (qnaigc.com)
**用途**: 卡通风格漫画图像生成

**主要功能**:
- 图像生成（同步模式）
- 支持多种参数（negative_prompt, aspect_ratio, human_fidelity等）

**配置**:
- API端点: `https://api.qnaigc.com/v1`
- 模型: `gemini-2.5-flash-image`（当前使用）
- 环境变量: `QINIU_API_KEY`
- 模式: 同步任务模式（直接返回图片URL）

## 📡 API路由

### `/api/script/generate`
**方法**: POST  
**功能**: 生成故事脚本或结构化分镜数据

**请求参数**:
```typescript
{
  prompt: string;                    // 用户提示词
  conversationHistory?: Array;       // 对话历史（可选）
  outputFormat?: 'script' | 'storyboard';  // 输出格式
}
```

**响应格式**:
```typescript
{
  success: boolean;
  data: {
    script?: string;                  // 文本脚本（outputFormat='script'）
    storyboard?: StoryboardData;      // 分镜数据（outputFormat='storyboard'）
  };
  error?: string;
}
```

### `/api/comic/generate`
**方法**: POST  
**功能**: 生成漫画绘本页面

**请求参数**:
```typescript
{
  scriptSegment?: string;            // 文本脚本片段（旧格式）
  storyboard?: StoryboardData;        // 分镜数据（新格式，优先）
  startPageNumber?: number;           // 起始页码
}
```

**响应格式**:
```typescript
{
  success: boolean;
  data: {
    pages: ComicPage[];               // 生成的页面数组
  };
  error?: string;
}
```

### `/api/comic/save`
**方法**: POST  
**功能**: 保存图片到本地存储

**请求参数**:
```typescript
{
  imageUrl: string;                   // 图片URL（支持base64）
  pageNumber: number;                 // 页码
  scriptId?: string;                  // 脚本ID（可选）
  segmentId?: number;                 // 片段ID（可选）
}
```

**响应格式**:
```typescript
{
  success: boolean;
  data: {
    url: string;                       // 保存后的本地URL
    fileName: string;                  // 文件名
    expiresAt: string;                // 过期时间（ISO格式）
  };
  error?: string;
}
```

### `/api/comic/cleanup`
**方法**: GET  
**功能**: 清理过期的图片文件

**响应格式**:
```typescript
{
  success: boolean;
  data: {
    deletedCount: number;              // 删除的文件数量
    message: string;                   // 清理结果消息
  };
  error?: string;
}
```

## 🔄 数据流

### 脚本生成流程
1. 用户输入提示词 → `ScriptGenerator`
2. 调用 `/api/script/generate` → API路由
3. API调用 `storyGenerator.ts` → DashScope 文本生成（三阶段：大纲→剧本→分镜）
4. 返回脚本/分镜数据 → 前端显示
5. 用户确认 → 保存到localStorage

### 漫画生成流程
1. 选择/导入脚本 → `ComicGenerator`
2. 脚本切分（如需要）→ `scriptUtils.ts`
3. 调用 `/api/comic/generate` → API路由
4. 解析脚本/分镜 → 生成图像提示词
5. 调用 `qiniu.ts` → 七牛云API生成图像
6. 调用 `/api/comic/save` → 保存图片到本地存储
7. 组装页面数据 → 返回前端
8. `ComicPageCanvas` 渲染 → 显示漫画
9. 保存漫画书到localStorage

### 用户认证流程
1. 用户点击登录 → `LoginModal`
2. 输入用户名密码 → `authUtils.login()`
3. 验证用户信息 → localStorage
4. 保存用户信息 → localStorage
5. 更新UI状态 → `MainLayout`

### 图片清理流程
1. 应用启动 → `layout.tsx` useEffect
2. 调用 `/api/comic/cleanup` → API路由
3. 扫描存储目录 → `imageStorage.ts`
4. 检查过期时间 → 删除过期文件
5. 返回清理结果 → 前端日志

## 📱 页面视图模式

项目支持以下视图模式（ViewMode）：
- `home` - 首页
- `script` - 脚本生成
- `comic` - 绘本生成
- `edit` - 脚本编辑
- `library` - 作品库
- `ai-create` - AI创作
- `my-works` - 我的作品
- `characters` - 角色管理
- `view-comic` - 查看漫画
- `personal` - 个人中心

## 🗂️ 存储结构

### localStorage键
- `comic_scripts` - 保存的脚本列表
- `comic_books` - 保存的漫画书列表
- `current_user` - 当前用户信息
- `is_logged_in` - 登录状态
- `users` - 用户列表
- `user_passwords` - 用户密码（实际应用应加密）

### sessionStorage键
- `currentViewMode` - 当前视图模式（用于状态恢复）

### 文件系统
- `public/comic-assets/` - 漫画图片存储目录
- `public/comic-assets/*.meta.json` - 图片元数据文件

## 🚧 当前限制与生产建议

- **认证增强**: 演示版用户数据存放在 `localStorage`。生产环境需接入数据库（如 PostgreSQL/MongoDB）并使用 JWT 或 Session 认证。
- **存储迁移**: 目前图片存放在 `public/comic-assets/`。生产环境建议迁移至阿里云 OSS 或 AWS S3，并结合 CDN 加速。
- **安全加固**: 已实现初步的 API Key 保护和频率限制，但仍需在生产网关层（如 Nginx 或 Cloudflare）配置更严格的防护。
- **密钥管理**: 严禁在代码中硬编码 API Key。生产部署必须通过环境变量或 Secret Manager 注入。
- **监控审计**: 建议接入 Sentry 等错误监控系统，并对 AI 接口调用进行审计日志记录。
